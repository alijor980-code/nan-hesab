حساب نان — نسخه PWA

این پوشه برای نصب به‌صورت اپ اندروید آماده شده است.
فایل‌ها را در یک سرویس میزبانی استاتیک با HTTPS قرار دهید (مثلاً GitHub Pages).
سپس نشانی HTTPS سایت را در Chrome اندروید باز کنید و از منوی سه‌نقطه گزینه Install app یا Add to Home screen را بزنید.

برای نصب PWA، باز کردن index.html به‌صورت فایل محلی کافی نیست؛ manifest و service worker به HTTPS (یا localhost) نیاز دارند.
اطلاعات حساب‌ها در حافظه محلی مرورگر ذخیره می‌شود. برای حفظ اطلاعات، مرتب از داخل برنامه پشتیبان بگیرید.
